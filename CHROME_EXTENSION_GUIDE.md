# How to Install Veyron OS as a Google Chrome Extension

You can now run Veyron OS directly in Google Chrome or any Chromium browser (Edge, Brave, Opera, Vivaldi) as a native Manifest V3 extension.

---

### Step 1: Open Chrome Extensions
1. In Google Chrome, go to the address bar and type:
   ```text
   chrome://extensions
   ```
2. In the top-right corner, **turn ON "Developer mode"**.

---

### Step 2: Load Unpacked Extension
1. Click the **"Load unpacked"** button in the top-left corner.
2. Select this project folder:
   ```text
   C:\Users\kavs1\OneDrive\Desktop\New folder (4)
   ```
3. Click **"Select Folder"**.

---

### Step 3: Launch Veyron OS!
There are two seamless ways to use Veyron OS:
1. **New Tab Override**: Press `Ctrl + T` to open a new tab — Veyron OS will boot automatically with the animated Fancy V logo!
2. **Toolbar Icon**: Click the Veyron OS icon (Fancy V) in your Chrome toolbar / extensions puzzle menu to launch it in a full tab anytime.
